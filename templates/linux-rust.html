{# ---------------- 8. Methodology ---------------- #}

Methodology

  • Every tagged release from {{ first.tag }} on is downloaded from the mainline tree, plus the newest release candidate when it is newer than the newest release.
  • Lines are counted with tokei: code lines exclude blanks and comments. C counts are *.c and *.h files.
  • Items, unsafe and calls into C are counted by parsing every .rs file with syn. The bodies of macro invocations and macro_rules! definitions are not parsed, so code generated by macros is not counted.
  • Vendored third-party crates ({% for c in data.crate_timeline | filter(attribute="kind", value="vendored") %}{{ c.name }}{% if not loop.last %}, {% endif %}{% endfor %}) are shown separately and left out of the first-party numbers.
  • A call into C is a call whose path goes through bindings::. Calls made through the safe wrappers in the kernel crate count once, at the wrapper.
